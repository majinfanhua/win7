# 分发前真机验证清单

> 支持范围：**Windows 7 SP1 / Windows 10**（各含 32/64 位）
> 原则：**先验免安装 zip，再验功能** —— 先确认能启动，再确认能用。

---

## 一、先确认该用哪个包

| 系统 | 位数 | 包 |
|---|---|---|
| Windows 7 SP1 | 64 位 | `AIEditor-*-win7-win10-x64.zip` |
| Windows 7 SP1 | 32 位 | `AIEditor-*-win7-win10-ia32.zip` |
| Windows 10 | 64 位 | `AIEditor-*-win7-win10-x64.zip` |
| Windows 10 | 32 位 | `AIEditor-*-win7-win10-ia32.zip` |

确认系统位数：右键「计算机 / 此电脑」→ 属性 → 系统类型。

> 一个包同时适用于 Win7 和 Win10，**不需要**按系统分开下载。
> 应用启动时自己识别系统，自动选择渲染策略。
>
> 包从哪拿：仓库 **Releases 页**（`latest` 为 main 滚动构建，`v*` tag 为正式版本），
> 或工作流**运行页**底部的 Artifacts（注意：任务日志页看不到 Artifacts）。

---

## 二、机器基线检查

在命令行执行 `winver`，或：

```bat
ver
wmic os get Caption,Version,ServicePackMajorVersion
```

| 检查项 | 要求 | 不符时 |
|---|---|---|
| 系统版本 | Win7 必须 **SP1**（6.1.7601）；Win10 任意版本 | 非 SP1 直接无法启动，必须升级 |
| VC++ 运行库 | 已装 2015-2022 | 先装 `vc_redist.x86.exe` / `vc_redist.x64.exe` |
| 可用内存 | ≥ 2 GB | 低于 2 GB 容易被杀进程 |

## 三、启动验证（重点）

1. 解压到 **纯英文、无空格** 的路径，例如 `D:\AIEditor`
   - 不要解压到「桌面」「下载」这类中文目录，也不要在 U 盘里直接跑
2. 双击 `AIEditor.exe`
3. **预期**：窗口 10 秒内出现，界面完整，标题「AI 教学编辑器」

| 现象 | 含义 | 下一步 |
|---|---|---|
| 窗口正常出现，可编辑代码 | 通过 | 进入第四节 |
| 完全无反应，进程一闪而过 | 缺运行库或系统非 SP1 | 看日志；补装 VC++ 运行库 |
| 窗口全白 / 全黑 | 图形兼容问题 | 看日志里的图形策略行；确认是否误设了 `--force-gpu`；仍白屏则加 `--software` 强制软件渲染 |
| 弹「不是有效的 Win32 应用程序」 | 位数不匹配 | 换 ia32 包 |
| 弹缺 DLL | 运行库缺失 | 记下缺哪个 DLL |
| 弹「界面进程异常退出」 | 渲染进程挂了 | 点「以软件渲染模式重启」，看是否恢复 |

## 四、功能自检

逐项勾选：

- [ ] 菜单「帮助 → 运行环境体检」：操作系统项应为「承诺支持」，截图保留
- [ ] 体检里「渲染模式」项：Win7 应显示**软件渲染**，Win10 应显示**硬件加速**
- [ ] 菜单「文件 → 打开文件夹」，左侧能出文件树
- [ ] 双击一个代码文件，编辑器能显示且**有语法高亮**
- [ ] 改一行代码，`Ctrl+S` 保存，重新打开确认已写入
- [ ] 中文输入法在编辑器内可正常输入中文
- [ ] 窗口最小化再恢复，界面正常（验证遮挡判定问题已规避）
- [ ] 窗口缩放到最小尺寸，布局不崩
- [ ] 菜单「帮助 → 打开日志目录」，能弹出日志文件夹

---

## 五、AI（中转站）验证

- [ ] 未配置时：AI 面板提示去设置，**不报错、不崩溃**
- [ ] 菜单「设置 → AI 模型」，填入中转站地址与密钥
- [ ] 地址可只填域名（如 `https://relay.example.com`），保存后能正常工作
- [ ] 点「拉取模型列表」，能出模型下拉框
- [ ] 选定模型后点「测试连接」，能返回延迟毫秒数
- [ ] 发一句提问，确认能**逐字流式返回**
- [ ] 生成中点「停止」，能中断
- [ ] 故意填错密钥，应提示「401 鉴权失败」而不是一堆英文堆栈

## 六、出问题时收集什么

日志目录：

```
%APPDATA%\AIEditor\logs
```

直接在资源管理器地址栏粘贴（把 `%APPDATA%` 换成实际路径）。

请提供：

1. 日志文件（`main-YYYY-MM-DD.log`）
2. 「运行环境体检」的完整结果
3. 系统位数（32/64）与具体版本号

这三样基本就能定位绝大多数问题。

## 七、常见问题速查

| 症状 | 根因 | 解决 |
|---|---|---|
| 双击无反应 | 非 SP1 / 缺 UCRT（KB2999226）| 装 SP1 + KB2999226 |
| 白屏黑屏 | 显卡驱动在 GPU 合成路径崩 | 确认未使用 `--force-gpu`；仍白屏则在快捷方式目标后加 `--software` |
| 字体发虚/错位 | Win7 无 Microsoft YaHei UI | 字体栈已兼容，若仍异常请截图 |
| 界面被放大后模糊 | Win7 高 DPI 缩放 | `Ctrl+0` 恢复默认缩放 |
| AI 报 404 | 中转站地址填错 | 只填域名或 `/v1` 即可，应用会自动补全 |
| AI 报 401 | 密钥无效 | 重新从中转站复制密钥 |
| 提示网络错误 | 系统代理或防火墙 | 应用已继承系统代理，检查 IE 代理设置 |
| 关闭窗口后进程残留 | 渲染进程未退出 | 任务管理器结束，并提交日志 |
